# Système d'embeddings - Vue d'ensemble
Voici une explication détaillée du fonctionnement de votre système d'embeddings pour la reconnaissance faciale :

## 1. Structure des données
### Fichiers principaux
- embeddings.pkl : Stocke un dictionnaire Python où les clés sont les identifiants de visage (face_id) et les valeurs sont les embeddings correspondants
- embeddings.index : Fichier d'index FAISS optimisé pour la recherche rapide de similarité
### Variables en mémoire
- embeddings_map : Dictionnaire {face_id → liste d'embeddings}
- faiss_index : Index FAISS pour la recherche rapide
- embedding_to_index : Liste qui fait correspondre chaque position dans l'index FAISS à un face_id
## 2. Flux de chargement au démarrage
1. Vérification des fichiers
   
   ```python
   if not os.path.exists(EMBEDDINGS_FILE):
       with open(EMBEDDINGS_FILE, 'wb') as f:
           pickle.dump({}, f)
    ```
   
   - Crée un fichier embeddings.pkl vide si nécessaire
2. Initialisation de l'index FAISS
   
   ```python
   faiss_index = init_faiss_index(embeddings_index_path=EMBEDDINGS_INDEX_PATH)
    ```
   ```
   
   - Crée un nouvel index FAISS ou charge un index existant
3. Chargement des embeddings
   
   ```python
   embeddings_map, faiss_index, embedding_to_index = load_embeddings(EMBEDDINGS_FILE, EMBEDDINGS_INDEX_PATH)
    ```
   ```
   
   - Charge le dictionnaire d'embeddings depuis embeddings.pkl
   - Charge l'index FAISS depuis embeddings.index
   - Reconstruit la liste embedding_to_index pour maintenir la correspondance
## 3. Processus de chargement détaillé (fonction load_embeddings)
1. Chargement du dictionnaire d'embeddings
   
   ```python
   with open(embeddings_file, 'rb') as f:
       embeddings_map = pickle.load(f)
    ```
2. Initialisation de l'index FAISS
   
   ```python
   faiss_index = faiss.IndexFlatL2(512)
   if os.path.exists(embeddings_index_path):
       faiss_index = faiss.read_index(embeddings_index_path)
    ```
   ```
3. Reconstruction de la liste de correspondance
   
   ```python
   embedding_to_index = []
   for fid, embeddings in embeddings_map.items():
       if isinstance(embeddings, list):
           embedding_to_index.extend([fid] * len(embeddings))
       else:
           embedding_to_index.append(fid)
    ```
   ```
   
   - Pour chaque face_id, ajoute autant d'entrées dans embedding_to_index qu'il y a d'embeddings
4. Vérification de cohérence et reconstruction si nécessaire
   
   ```python
   if faiss_index.ntotal != len(embedding_to_index):
       # Réinitialisation et reconstruction complète
    ```
   ```
   
   - Si le nombre d'embeddings dans l'index FAISS ne correspond pas à la liste de correspondance, tout est reconstruit
## 4. Ajout d'un nouveau visage
1. Prétraitement des images
   
   - Les images base64 sont converties en images OpenCV
   - Amélioration de la qualité (CLAHE, accentuation des contours, etc.)
2. Extraction des embeddings
   
   - DeepFace.extract_faces détecte les visages
   - DeepFace.represent génère les embeddings (vecteurs de 512 dimensions)
3. Stockage des embeddings
   
   ```python
   embeddings_map[face_id] = embeddings
    ```
   
   - Tous les embeddings d'un visage sont associés à un seul face_id
4. Mise à jour de l'index FAISS
   
   ```python
   for emb in embeddings:
       embedding_to_index.append(face_id)
       faiss_index.add(embedding_array)
    ```
   
   - Chaque embedding est ajouté à l'index FAISS
   - Le face_id correspondant est ajouté à embedding_to_index
5. Persistance des données
   
   ```python
   with open(EMBEDDINGS_FILE, 'wb') as f:
       pickle.dump(embeddings_map, f)
   faiss.write_index(faiss_index, EMBEDDINGS_INDEX_PATH)
    ```
   ```
   
   - Sauvegarde du dictionnaire et de l'index FAISS
