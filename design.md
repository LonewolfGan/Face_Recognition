====================================================
AI DESIGN EXECUTION RULES
====================================================

The project uses the following MCP tools and design systems:

- Magic UI MCP
- shadcn/ui MCP
- Figma MCP
- Chrome DevTools MCP
- Framer Motion
- Aceternity-inspired interactions and layouts

The AI MUST intelligently combine these tools to create a premium and cohesive experience.

====================================================
MCP USAGE STRATEGY
====================================================

====================================================
MAGIC UI MCP
====================================================

Use Magic UI MCP for:
- hero sections
- animated backgrounds
- spotlight effects
- grid patterns
- glowing buttons
- premium SaaS sections
- smooth interactive cards
- futuristic UI effects
- premium loading states
- animated borders

Preferred Magic UI elements:
- Spotlight
- Grid Pattern
- Animated Beam
- Border Beam
- Aurora Background
- Bento Grid
- Meteors
- Shimmer Buttons
- Marquee
- Dock
- Animated Testimonials

DO NOT:
- overuse animations
- overload the interface
- stack effects excessively

Use Magic UI subtly and elegantly.

====================================================
SHADCN/UI MCP
====================================================

Use shadcn/ui ONLY as:
- foundational component system
- accessibility layer
- structural UI primitives

Use shadcn for:
- dialogs
- dropdowns
- sheets
- tabs
- tooltips
- popovers
- command menus
- forms
- inputs
- select menus
- tables
- navigation menus

IMPORTANT:
Do NOT generate default shadcn dashboards.

All shadcn components MUST be:
- heavily customized
- visually elevated
- redesigned to match the futuristic design system

Avoid:
- default shadcn styling
- generic gray layouts
- boring admin panel appearance

====================================================
FIGMA MCP
====================================================

When a Figma design is connected:

The Figma design becomes the PRIMARY visual reference.

The AI MUST:
- preserve spacing density
- preserve hierarchy
- preserve proportions
- preserve atmosphere
- preserve visual rhythm
- preserve card sizing
- preserve section composition

The AI MUST NOT:
- simplify the design
- flatten the UI
- replace the layout with generic SaaS patterns

====================================================

- inspect layouts visually

- refine motion smoothness

====================================================
ANIMATION EXECUTION RULES
====================================================

Animations MUST:
- support the experience
- improve perceived quality
- guide user attention

Animation durations:
- fast interactions: 150ms–200ms
- hover transitions: 200ms
- section reveals: 300ms–500ms
- page transitions: 350ms–500ms

Preferred easing:
- easeOut
- easeInOut
- custom smooth cubic-bezier

Avoid:
- aggressive elastic motion
- random floating animations
- excessive parallax

====================================================

The mobile experience MUST:
- preserve premium aesthetics
- maintain spacing quality
- avoid broken layouts
- keep visual hierarchy intact

Use:
- bottom navigation
- compact premium cards
- swipeable sections
- intelligent stacking
